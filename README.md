# MoodyView

🎉 MoodyView is a macOS app that lets you select modes from the menu bar and automatically change your desktop wallpaper.  

---

## Features
- Select modes directly from the menu bar
- Set multiple images for each mode
- Automatically change wallpaper according to the selected mode
- Settings window to manage:
  - Theme (Light / Dark / System)
  - Developer info

---

## Installation
1. Download the latest DMG file from the [Releases](https://github.com/doyeon789/MoodyView/releases/tag/v1.0.0) page.
2. Drag `MoodyView.app` to your **Applications** folder.
3. Launch the app and select a mode from the menu bar.
